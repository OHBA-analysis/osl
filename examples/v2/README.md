# Scripts written for osl-ephys 2.4

These scripts target the v2 API (`run_proc_batch`, `run_src_batch`, the
`source_recon` config section, the per-subject report pages) and are kept
as they were published: the toolbox paper's analysis (`toolbox-paper/`),
the Oxford pipelines (`oxford/`), the MNE sample dataset walkthrough
(`wh_mne/`) and the beamformer comparison. They do not run on v3; see the
migration page of the documentation for what changed, and the scanner
directories above for the v3 equivalents.
